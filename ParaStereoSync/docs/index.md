# ParaStereoSync Documentation

This documentation supports software publication and reproducible use of ParaStereoSync.

## Software Scope

Main software:
1. `ParaStereoSync.py` (stereo synchronization and tracking GUI)
2. `KineVis3D.py` (3D visualization and analysis GUI)

Supporting tools:
1. `VidTrim.py`
2. `TempArUco.py`
3. `tkCalib2.py`
