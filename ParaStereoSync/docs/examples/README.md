# Examples

This folder contains runnable example templates to help you reproduce common workflows. They are lightweight templates that expect you to replace file paths with your own data.

Files
- `run_tracking_example.py` — template script showing how to call `eccTrackVideo` programmatically.

How to use
1. Open `run_tracking_example.py` and edit the `VIDEO_PATH`, `TEMPLATE_CSV` and `OUTPUT_CSV` variables to point to your files.
2. Run the script inside the `stereosync` environment:

```bash
python docs1111/examples/run_tracking_example.py
```
